# Maps4U Street Map System (`maps4u-maps`)

Deterministic, repeatable pipeline that turns a user-drawn geofence and paper-size choice (`A3`/`A4`/`A5`, `landscape`/`portrait`) into a reviewable, print-ready vector PDF street map in the Maps4U style.

## Quickstart (Local / Dev Container)

```bash
pip install -e ".[dev]"
make lint
make test
make run
```
