# Maps4U Security & Operational Threat Model (`v1.0.2`)

| Threat Category | Attack Vector / Operational Risk | Enforced Mitigation (`v1.0.2`) |
| :--- | :--- | :--- |
| **1. Production Credential Weakness & URL Token Leakage (`SEC-001`, `SEC-002`, `SEC-003`)** | Deployment starts with default/weak tokens (`maps4u-prod-operator-token`), leaks tokens via `?token=` query strings in access logs/history, or allows operators to forge reviewer identities via `X-Operator-Identity` or JSON body strings. | `docker-compose.yml` requires explicit `${MAPS4U_OPERATOR_TOKEN:?...}` and `${MAPS4U_REVIEWER_TOKEN:?...}` secrets. `validate_production_credentials()` refuses startup or returns `503` if tokens are missing, `< 16` chars, match known defaults, or are identical. Query-string `?token=` auth is rejected (`401`). Principal identities are bound strictly to server-configured `MAPS4U_OPERATOR_IDENTITY` and `MAPS4U_REVIEWER_IDENTITY`. |
| **2. Historical OSM Cache Overwrite & Input Drift (`DATA-001`, `DATA-002`, `DATA-003`)** | Subsequent jobs for the same BBox refresh Overpass data and overwrite `.raw.json`/`.gpkg` snapshots referenced by approved jobs, or live `style.yaml`/`corrections.yaml` edits silently alter `reproduce()`, or `.gpkg` corruption yields empty layers. | `compute_cache_lookup_key(bbox, query)` (`<lookup_key>.latest.json`) is separated from content-addressed `compute_snapshot_id(bbox, query, raw_sha256)` (`INSERT OR IGNORE INTO osm_snapshots`). Exact `style.yaml`, `paper_templates.yaml`, and `corrections.yaml` files are frozen in `jobs/<job_id>/frozen_inputs/` and verified by SHA-256 during `reproduce()`. Corrupted `.gpkg` layers auto-recover from verified `.raw.json` or fail with `422 E_STORAGE`. |
| **3. Duplicate Dispatch, Abandoned Retries & Masked Celery Failures (`QUEUE-001`, `QUEUE-002`, `QUEUE-003`)** | Concurrent `/run` calls spawn duplicate workers on one job, `/retry` updates status without executing, or Celery tasks swallow pipeline errors and report `SUCCESS`. | Atomic SQLite status claiming (`WHERE status IN ('created', 'queued')`) and in-process `try_acquire_job_claim()` reject duplicate dispatches (`409`). `/retry` increments `retry_count`, logs `job.retry_requested`, and immediately executes (`inline`) or enqueues (`celery` with backoff). `run_job_task` retries transient errors (`E_OVERPASS_UNAVAILABLE`, `E_OVERPASS_RATE_LIMIT`) and re-raises terminal `Maps4UError` so Celery records `FAILURE`. |
| **4. Malicious Geofence Input & Unsafe File Access (`BUG-003b`, `BUG-007`, `BUG-013`)** | Caller submits oversized/invalid geometry, collides revision IDs across projects, or passes `../` in `style_ref` or `corrections_ref`. | `validate_and_canonicalise_geofence` enforces `Polygon`/`MultiPolygon`, `<= 200` vertices/ring, `<= 3` parts, and `<= 600.0 km²`. Revisions are scoped per `project_id`. `resolve_safe_corrections_path` and `load_style_by_ref` block path traversal and files outside `MAPS4U_DATA_DIR`. |
| **5. QA Bypass & Post-Approval Tampering (`QA-001`, `BUG-008`, `BUG-015`)** | A job with QA blockers or stubbed files transitions to `proof_ready`/`finalized`, or `proof.pdf` is modified on disk after sign-off. | Runtime QA test-stub shortcuts are removed (`QA-001`). `verify_governed_qa_and_pdf()` gates `proof_ready` and `finalized` on `qa.passed == True`, `blocker_count == 0`, valid 1-page `%PDF-`, and `manifest.json` SHA-256 parity (`422 E_QA_FAILED`). `GET /api/jobs/{id}/artifacts/{name}` re-verifies SHA-256 against `manifest.json` and `review_decisions.proof_sha256` (`409 E_STORAGE`). |
| **6. False-Positive Readiness (`OPS-001`)** | Load balancer routes traffic to an API instance whose SQLite DB, Redis broker, or Celery worker pool is down. | `GET /readyz` executes `SELECT 1` + `schema_migrations` check on SQLite and, when `MAPS4U_QUEUE=celery`, verifies Redis `PING` and active Celery worker `control.inspect().ping()`, returning `503` when any component is unavailable. |
