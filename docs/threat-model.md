# Maps4U Security & Operational Threat Model (`v1.0.1`)

| Threat Category | Attack Vector / Operational Risk | Enforced Mitigation (`v1.0.1`) |
| :--- | :--- | :--- |
| **1. Unauthenticated / Unauthorized API Access (`BUG-003`)** | Anonymous caller or operator without reviewer privileges attempts to create projects, dispatch jobs, download governed artifacts, or sign off proofs in production. | `maps4u.api.deps` enforces Bearer token / `X-Operator-Token` / `X-Reviewer-Token` authentication (`hmac.compare_digest`). When `MAPS4U_ENV` is `prod` or `staging`, missing tokens fail closed (`503 E_AUTH_FORBIDDEN`). Role separation (`operator` vs `reviewer`) is enforced on `approve`/`reject` vs `create`/`run`/`corrections`. |
| **2. Malicious or Oversized Geofence Input** | Operator or API caller submits a huge polygon (e.g., continent-sized) or degenerate self-intersecting ring to exhaust memory or Overpass quota. | `maps4u.geo.crs.validate_and_canonicalise_geofence` enforces `Polygon`/`MultiPolygon` type, Shapely `is_valid` check, `<= 200` vertices per ring, `<= 3` multipolygon parts, and metric UTM area `<= 600.0 km²` (`E_GEO_INVALID`, `E_GEO_TOO_LARGE`). Revisions are scoped per `project_id` (`BUG-007`). |
| **3. Unsafe YAML Deserialization / Path Traversal (`BUG-002`, `BUG-013`)** | Crafted client corrections, style reference (`../`), or artifact filename attempts arbitrary Python object instantiation or path traversal. | Parsed strictly via `yaml.safe_load` and validated against `schemas/corrections.schema.json` and `schemas/style.schema.json`. `load_style_by_ref` rejects path traversal (`..`, leading `/`). Artifact downloads whitelist `GOVERNED_OUTPUT_FILES`. |
| **4. Upstream Overpass Rate-Limiting / Stale Cache (`BUG-015`)** | Concurrent requests trigger HTTP 429/504 from Overpass, or stale/corrupted cache files are served silently. | `OverpassClient` enforces a process-wide `BoundedSemaphore(MAPS4U_OVERPASS_MAX_CONCURRENCY)` and configurable timeout (`MAPS4U_OVERPASS_TIMEOUT_S`), backed by a 3-attempt backoff ladder (`10s`, `30s`, `90s`). `lookup_cached_snapshot` enforces `MAPS4U_CACHE_MAX_AGE_DAYS` expiry (`0` = unlimited, `>0` = max age in days) and verifies raw JSON `SHA-256` against SQLite before returning a cache hit. |
| **5. Failed QA Bypass or Unaudited Proof Tampering (`BUG-006`, `BUG-008`, `BUG-015`)** | A job with QA blockers is transitioned to `proof_ready`/`finalized`, a finalized job is overwritten by duplicate submission, or `proof.pdf` is modified on disk after approval. | `transition_job_state` and `execute_job_pipeline` gate `proof_ready` and `finalized` on `qa.passed == True`, `blocker_count == 0`, valid 1-page `%PDF-` header/structure, and `manifest.json` SHA-256 parity (`E_QA_FAILED`). Duplicate `POST /api/jobs` submissions return `409 E_STATE_ILLEGAL` (`INSERT` only, never `INSERT OR REPLACE`). `GET /api/jobs/{id}/artifacts/{name}` re-verifies artifact `SHA-256` against `manifest.json` and `review_decisions.proof_sha256` on every download (`409 E_STORAGE` on tampering). |
| **6. Non-Deterministic / Hallucinated Output** | Nondeterministic label placement or AI inference alters street geometry or names. | Zero AI/LLM components exist in the runtime pipeline. All spatial indexing (`STRtree`), sorting (`osm_id` tie-breaking), and PDF metadata timestamps are 100% deterministic. |
